# Autumn Pixel

Оригинальный пиксельный шрифт для Autumn. Геометрия букв описана в исходнике;
существующие шрифты не использовались для трассировки или встраивания.

## Файлы

- `AutumnPixel-Regular.ttf` — устанавливаемый TrueType, 188 символов.
- `AutumnPixel Bitmap.asset` — готовый статический шрифт TextMeshPro с материалом
  и единственным атласом 512×512 внутри asset.
- `Characters.txt` — полный набор символов для запекания атласа.
- `Source/build_autumn_pixel.py` — исходные рисунки символов и сборщик TTF.

Включены прописные и строчные английские и русские буквы, `Ё/ё`, цифры,
ASCII-пунктуация, русские кавычки, длинное и короткое тире, многоточие,
`№`, `₽`, `$`, `€`, `£`, `%`, `±`, `×`, `÷`, стрелки и пробелы.
Ширина цифр одинакова. Содержимое перечислено в Characters.txt.

## Unity

Назначать `AutumnPixel Bitmap.asset` в поле Font Asset компонента TMP.
Шрифт подключён к существующим InventoryWindow и ItemInfoWindow.
Глобальные TMP Settings сохранены: используемый там шрифт по умолчанию
отличается от штатного LiberationSans и этой задачей не заменяется.

Атлас запечён в режиме RASTER при Sampling Point Size 16, Padding 3,
размере 512×512, Scale 1. Фильтрация Point, mipmaps отсутствуют,
Atlas Population Mode Static, дополнительные атласы отключены.
Все 188 символов находятся в этом атласе; для русского и английского
текста не требуется подстановка из другого шрифта.

При Canvas Scale 1 полностью целая пиксельная сетка получается на размерах
16, 32, 48, 64. В компактных полях ItemInfoWindow также используется 24.
Размеры в текущих префабах: заголовок инвентаря 48, название предмета 32,
описание/цена/плашка экипировки 24, тип предмета 16. AutoSize отключён.
Проверено при целевом разрешении 1920×1080.

Надписи на плашках — отдельные TMP-объекты. Их дочерний TextBackground
перекрывает старые буквы в исходных PNG, сохраняя декоративные края.
PNG, рамки, цвета светлого фона и привязки контроллера InventoryWindow
не изменены.

В ItemInfoWindow добавлены поля Content/ItemName, ItemType, Description,
Price и EquippedBadge/Label. Это поля визуального макета: подключение
данных предмета и переключение языков не добавлялись.

Предпросмотры: `ArtSource/UI/Fonts/AutumnPixel-Proof.png` и
`ArtSource/UI/Fonts/AutumnPixel-Windows-1920x1080.png`.
Второй показывает временные русские и английские примеры в реальных
префабах. Тексты примеров не сохранены как игровые предметы.

## Обновление

Сборщику требуется Python 3.10+ и FontTools. Из корня проекта:

```text
python Assets/Art/Fonts/AutumnPixel/Source/build_autumn_pixel.py
```

После изменения рисунков букв заново запечь статический TMP-атлас через
Font Asset Creator с настройками выше и набором из Characters.txt.
Сборщик проверяет полноту обоих алфавитов и повторно читает полученный TTF.
