# Autumn

2D RPG на Unity с пиксельной графикой.
Данж процедурно собирается из заранее сгенерированных комнат.
Основной визуальный и игровой референс — Stoneshard.
Целевое направление — хардкорная RPG в тёмном фэнтезийном сеттинге.
Конкретные механики сложности и детали сеттинга определяются отдельно.

Сюжет и конкретные механики определяются требованиями этого проекта.
Референс и похожая кодовая основа не означают перенос контента или требований
из других игр.

## Кодовая основа

Разработка следует принципам SOLID и GRASP. Бизнес-логика отделяется
от интеграции с Unity. Для связывания зависимостей и запуска систем
используются существующие конфигураторы, DI и FSM.

Мобы, предметы и интерактивные объекты собираются из модулей.
Настройки объекта, изменяемое состояние экземпляра и поведение разделены.
Для каждого определения модульного объекта используется отдельный
`ModuleItemGameConfig`; новые конфиги размещаются в `Assets/Configs/`.

Новые тесты на текущем этапе не пишем, но бизнес-логику проектируем
с учётом будущего тестирования. Существующие тесты сохраняются.

## Структура проекта

| Папка | Назначение |
| --- | --- |
| `Assets/App/Common/` | Переиспользуемая инфраструктура и модульная система объектов. |
| `Assets/App/Game/` | Игровые механики и интеграция конкретной игры. |
| `Assets/App/Generation/` | Алгоритмы, конфиги и данные процедурной генерации. |
| `Assets/App/Game/Dungeon/` | Создание игровой модели данжа и Unity-представления. |
| `Assets/Prefabs/Tiles/Rooms/` | Подготовленные префабы комнат. |
| `Assets/Configs/` | Все новые конфиги и их данные. |

## Генерация данжа

Текущий `DungeonGenerator` использует `TileBasedDungeonGenerator`:
выбирает настроенные варианты комнат и собирает из них данж через выходы.
Игровая интеграция создаёт модель и представление данжа; игрок размещается
в стартовой комнате.

В кодовой основе также сохранены другие варианты генерации.
Их наличие не означает, что все шаги выполняются в текущем алгоритме.
Описание активного подхода и точки входа — в [архитектуре](docs/architecture.md).
